# CSV Summarize

A browser-based tool for loading a CSV file and viewing a summary, table, and
charts of its contents. All processing happens locally in the browser — no
file is ever uploaded to, or stored on, any server.

Built with Svelte 5, Tailwind CSS 4, and shadcn-svelte.

## Development

```sh
bun install
bun run dev
```
